# ML-Phishing-Email-Detection

## Project Overview
This senior design project compares multiple machine learning algorithms for detecting phishing emails.

The models being evaluated are:
- Logistic Regression
- Random Forest
- Support Vector Machine (SVM)

## Technical Approach
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Datasets
Primary training dataset:
- CEAS_08

Additional testing datasets:
- Enron
- Ling

## Project Pipeline
1. Load public email datasets
2. Clean and preprocess the email data
3. Extract text/features
4. Split data into trainign and testing sets
5. Train Logistic Regression, Random Forest, and SVM
6. Evaluate each model
7. Compare results

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- False Positive Rate (FPR)
- Confusion matrix
