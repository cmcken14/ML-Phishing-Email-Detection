# Datasets

This project uses public phishing email datasets curated by Champa, Rabbi, and Zibran.

The datasets are not included in the repository.

Datasets used:
- CEAS-08: https://zenodo.org/records/8339691?preview_file=CEAS_08.csv
- Enron: https://zenodo.org/records/8339691?preview_file=enron.csv
- Ling: https://zenodo.org/records/8339691?preview_file=ling.csv

  A. I. Champa, M. F. Rabbi, and M. F. Zibran, “Curated datasets and feature analysis for phishing email detection with machine learning,” in 3rd IEEE International Conference on Computing and Machine Intelligence (ICMI), 2024, pp. 1–7
